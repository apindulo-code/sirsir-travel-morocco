# SirSir Travel Morocco 🇲🇦

تطبيق Flutter لمساعدة المسافرين على اكتشاف المغرب والتخطيط للتنقل بين المدن، مع مركز معلومات للطقس والبحر ومواقيت الصلاة ودليل المدن المرشحة لكأس العالم 2030.

## الوظائف الحالية

- لوحة معلومات السفر: الطقس الحالي وتوقعات خمسة أيام ومواقيت الصلاة وبيانات الأمواج عند توفرها.
- تحديد الموقع عبر GPS بعد موافقة المستخدم، مع تحديد أقرب مدينة مغربية وحفظ آخر مدينة مختارة.
- اختيار المدينة يدوياً عند عدم توفر GPS.
- شريط عناوين أخبار السفر بلغات متعددة، مع فتح المقال لدى مصدره.
- خريطة المغرب ونقاط الوجهات السياحية.
- مخطط مسار بري بين المدن باستخدام OSRM، مع خيار فتح الاتجاهات في Google Maps.
- واجهة بالعربية والإنجليزية والفرنسية والإسبانية، مع حفظ اللغة المختارة.
- حسابات Firebase: البريد وكلمة المرور، التحقق من البريد، ورمز SMS عند تفعيل مزود الهاتف.
- طلبات الحجز للمستخدم المسجل محفوظة في Firestore ويمكن عرضها وإلغاؤها داخل التطبيق.
- روابط مباشرة لمنصات النقل والمعلومات الرسمية.
- دليل مواقع كأس العالم 2030 المرشحة في المغرب، مع توضيح أن الاختيار النهائي للملاعب لم يُحسم بعد.

## مصادر البيانات والخدمات

- Open-Meteo: الطقس.
- Open-Meteo Marine: بيانات الأمواج عند توفرها.
- Aladhan: مواقيت الصلاة؛ يجب مطابقتها مع التوقيت المحلي المعتمد.
- Google News RSS: عناوين الأخبار وروابط الناشرين.
- OpenStreetMap: طبقات الخرائط.
- OSRM: حساب المسارات البرية.
- Firebase Authentication وCloud Firestore: الحسابات وطلبات المستخدمين.

تخضع الخدمات الخارجية للتوفر وسياسات الاستخدام وحدود الطلبات. لا تمثل التقديرات الجوية أو البحرية تحذيراً رسمياً أو ضماناً للسلامة.

## تشغيل المشروع

يتطلب Flutter stable وDart 3.3 أو أحدث.

```bash
flutter pub get
flutter run
```

لإنشاء Android APK:

```bash
flutter build apk --release
```

لإنشاء نسخة الويب:

```bash
flutter build web --release
```

يقوم GitHub Actions ببناء APK ونسخة الويب ورفعها كـ artifacts عند تحديث الفرع الرئيسي.

## إعداد Firebase قبل تفعيل الحسابات السحابية

1. مع نسخة التوزيع المحدود، يجب أن يكون تطبيق Android مسجلاً في Firebase بمعرف الحزمة `ma.sirsirtravel.morocco.limited`؛ التسجيل القديم `ma.sirsirtravel.morocco` محفوظ ولا يُحذف. أضف تطبيق Android جديداً في مشروع Firebase نفسه قبل اعتماد النسخة الجديدة، ثم حدّث `lib/firebase_options.dart` بمعرّف تطبيق Android الجديد.
2. فعّل Email/Password وPhone من Firebase Authentication.
3. أضف بصمات SHA-1 وSHA-256 لتطبيق Android لاستخدام التحقق الهاتفي.
4. أنشئ قاعدة Firestore وانشر `firestore.rules` و`firestore.indexes.json`.
5. تم تسجيل تطبيق Web في Firebase وإضافة إعداداته إلى `lib/firebase_options.dart`؛ أصبح الكود يختار إعدادات Android أو Web تلقائياً.
6. انشر قواعد Firestore بعد مراجعتها واختبر التسجيل بالبريد والهاتف على Android والويب قبل استقبال المستخدمين.

راجع [دليل إعداد Firebase بالعربية](FIREBASE_SETUP_AR.md).

## حدود مهمة قبل الإطلاق

- الرحلات والأسعار التجريبية ليست جداول ناقلين مباشرة ولا عروضاً مؤكدة.
- طلب الحجز المحفوظ في SirSir ليس تذكرة نقل رسمية ولا يحجز مقعداً لدى شركة النقل.
- إتمام شراء التذاكر يتم عبر المواقع الرسمية للناقلين.
- بيانات ملاعب ومدن 2030 المعروضة معلومات مرشحة؛ يجب تحديثها من إعلانات FIFA الرسمية.
- يلزم إعداد ومراجعة سياسة الخصوصية وشروط الاستخدام ووسيلة دعم رسمية قبل النشر العام.
- يلزم اختبار التطبيق على أجهزة فعلية ومراجعة أداء الخرائط والخدمات الخارجية وأذونات الموقع قبل الإطلاق.

## الأمان

لا تضع كلمات مرور أو مفاتيح خدمة Firebase أو ملفات service-account في المستودع. حماية بيانات المستخدم تعتمد على نشر قواعد Firestore واختبارها، وليس على إخفاء إعدادات تطبيق العميل.
